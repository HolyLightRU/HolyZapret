# Old strategy — архив корневых `general.bat`

Здесь лежат старые версии корневого `general.bat` из истории репозитория.
Файлы сохранены байт-в-байт для истории и сравнения.

> Это архив, а не рабочая папка. Запускать эти `.bat` отсюда нельзя:
> они рассчитывают на `bin\`, `lists\` и другие файлы в корне HolyZapret.
> Актуальная рабочая стратегия находится в корне: `..\general.bat`.

- `1.4.3` и `2.0.0` — одинаковое содержимое `general.bat`.

  Версии 2.0.2 и 2.0.3 меняли другие файлы (в частности, `lists/hosts-list.txt`).
